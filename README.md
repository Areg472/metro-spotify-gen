## Welcome :>

I LOVE MUSIC. I always listen to music during my metro trips.

So I created this cool project called metro uhh spotify thing, which generates a track list based on your last 50 songs and your metro trip :D

### Currently supported cities:
- Minsk
- Yerevan(my hometown)
- Tbilisi
- London(coming soon)

To use this locally you have to download the project and stuff but I recommend just going to https://spotify-metro.aregus.me/

IF YOU STILL WANT TO USE IT LOCALLY U NEED TO DOWNLOAD THIS WHOLE THING DO NPM INSTALL THEN PUT 4 ENVS

```
SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=
NEXT_PUBLIC_REDIRECT_URL=
AI_GATEWAY_API_KEY=
```

and do npm build + npm start
